# Ling-Pad

A lightweight, browser-based text pad with linguistic utilities.

## Features

- Write and edit text in a clean, distraction-free interface
- Word count, character count, and sentence count
- Basic linguistic analysis (word frequency, average word length)
- Export text to a `.txt` file

## Getting Started

Open `index.html` in any modern web browser — no build step required.

## Development

```bash
# Install dev dependencies (optional, for linting)
npm install

# Run a local server
npx serve .
```
